# Deprecated `stable` branch

This branch is retired and intentionally contains no installable SpringBrand
Plugin package.

Production installation always follows repository `main`:

```text
https://github.com/springbrand-lab/springbrand-agent-setup
```

Development installation uses only the immutable dev tag documented in:

```text
https://github.com/springbrand-lab/springbrand-agent-setup/blob/main/INSTALL.dev.md
```

Do not add this `stable` branch as a Marketplace or Plugin source.
